# FE–Core 개발 경계

현재는 개발 환경 초기화 단계입니다. 아래 역할은 향후 구현 책임을 구분하며 구현 완료를 의미하지 않습니다.

## Frontend 담당
- 자연어 입력 UI와 입력 데이터 관리
- 제출 이벤트 처리와 입력 유효성 검사
- 전송 상태 관리와 수신 결과 UI 출력

## Rust Core 담당
- Core 수신 인터페이스
- 요청 데이터 수신 및 Core 측 요청 검증
- 실제 입력 원문 수신 확인
- 수신 결과 생성

## 공동 결정 사항 — 모두 미확정
- Tauri Command 이름
- IPC 요청 데이터 구조
- IPC 응답 데이터 구조
- 오류 반환 형식
- 수신 성공 판정 기준

src-tauri/는 Core 담당 영역입니다. 초기 코드에는 사용자 입력 Command와 업무 로직이 없습니다.
FE는 향후 src/features/user-input/transport/를 통해 통신을 분리합니다.
Mock Gateway는 실제 Core 수신을 증명하지 않으며, 실제 수신 성공 판정은 합의된 IPC 계약으로 검증해야 합니다.
